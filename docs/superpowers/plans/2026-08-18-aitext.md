# Aitext v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Aitext, a Windows-native light code notepad with one-suggestion ghost-text completion against a user-configured OpenAI-compatible API.

**Architecture:** One process, three crates. `aitext-core` owns documents and editing. `aitext-ai` owns debounce, generations, shaping, and the OpenAI-compatible client. `aitext` is the egui/eframe shell that paints, routes keys, and stores settings. Ghost text is a preview until Tab writes it into the document.

**Tech Stack:** Rust 1.85+ (edition 2021), Cargo workspace, `ropey`, `encoding_rs`, `eframe`/`egui`, `reqwest` + rustls, `toml` + `serde`, Windows DPAPI via the `windows` crate. No Node, no WebView, no Helix, no Copilot LS.

**Spec:** [docs/superpowers/specs/2026-08-18-aitext-design.md](../specs/2026-08-18-aitext-design.md)

## Global Constraints

- v1 is Windows only. Do not add macOS/Linux support work.
- Offsets are Unicode scalar values (Rust `char`s), never bytes and never UTF-16 code units.
- Insert mode only. No overwrite / overtype mode and no INS indicator.
- Soft open limit 8 MiB editable; 8-16 MiB read-only and no completion; above 16 MiB refuse.
- One ghost suggestion. Tab accepts, Esc rejects. No completion list.
- Debounce default 250 ms, settings range 100-800 ms.
- Completion cap 120 characters or 4 lines, whichever is hit first. Temperature 0.2. Request timeout default 8 seconds.
- After 3 consecutive failures on the same document, wait 5 seconds before another request.
- API key lives under `%APPDATA%\\Aitext\\` protected with DPAPI. Never write it into `config.toml`, git, logs, or crash reports.
- HTTPS is required unless the user sets allow plaintext HTTP.
- Tests must not call live model APIs. Use a fake transport.
- Do not copy Helix or Notepad++ source. Those repos are behavior references only.
- If a feature is not in the spec, it is out of v1. No file tree, plugins, LSP, debugger, terminal, multi-caret, minimap, folding, command palette, session restore, regex find, or prompt editor.
- License new Aitext source as MIT.
- v1 ships as a portable `aitext.exe` plus README. No installer.

## Task 3: Undo coalescing

**Files:**
- Create: `crates/aitext-core/src/undo.rs`
- Modify: `crates/aitext-core/src/document.rs`
- Modify: `crates/aitext-core/src/lib.rs`

**Interfaces:**
- Consumes: `Document::insert`, `replace_selection`, `delete_backward`, `delete_forward`
- Produces:

```rust
impl Document {
    pub fn undo(&mut self) -> bool;
    pub fn redo(&mut self) -> bool;
    pub fn can_undo(&self) -> bool;
    pub fn can_redo(&self) -> bool;
}
```

An undo record is one contiguous insert or one contiguous delete, plus the selection before and after. Consecutive ASCII-or-CJK inserts with no caret jump coalesce into one undo step while each insert is within 800 ms of the previous one **or**, simpler and required here: coalesce consecutive inserts that each have length 1 and happen with no intervening non-insert command. Deletes do not coalesce with inserts. `undo` restores text and selection. A new edit after undo clears the redo stack.

## Task 5: Encoding, newlines, and size class

**Files:**
- Create: `crates/aitext-core/src/encoding.rs`
- Modify: `crates/aitext-core/src/document.rs`
- Modify: `crates/aitext-core/src/lib.rs`

**Interfaces:**
- Consumes: locked `Encoding`, `NewlineStyle`, `SizeClass`, `SOFT_LIMIT_BYTES`, `HARD_LIMIT_BYTES`
- Produces:

```rust
pub fn classify_size(byte_len: u64) -> SizeClass;
pub fn decode_bytes(bytes: &[u8]) -> Result<(String, Encoding, NewlineStyle), DecodeError>;
pub fn encode_text(text: &str, encoding: Encoding) -> Result<Vec<u8>, EncodeError>;
pub fn majority_newline(text: &str) -> NewlineStyle;

impl Document {
    pub fn encoding(&self) -> Encoding;
    pub fn set_encoding(&mut self, encoding: Encoding);
    pub fn newline_style(&self) -> NewlineStyle;
    pub fn open_bytes(bytes: &[u8]) -> Result<Self, OpenError>;
    pub fn encode(&self) -> Result<Vec<u8>, EncodeError>;
}

pub enum OpenError { TooLarge, Decode(DecodeError) }
pub enum DecodeError { Unsupported }
pub enum EncodeError { Unsupported }
```

Detection rules, in order:

1. `classify_size` on `bytes.len()`. `TooLarge` becomes `OpenError::TooLarge` and does not decode.
2. BOM `EF BB BF` => UTF-8 BOM. `FF FE` => UTF-16 LE. `FE FF` => UTF-16 BE.
3. Else if valid UTF-8, including empty, => UTF-8.
4. Else decode with `encoding_rs::GBK`. If the decoder reports errors, return `DecodeError::Unsupported`.
5. `majority_newline`: count `\r\n` as CRLF units and remaining `\n` as LF units. Tie or none => `Lf`.
6. `open_bytes` sets readonly when class is `ReadOnly`.
7. `encode_text` writes the matching BOM for `Utf8Bom`, `Utf16Le`, `Utf16Be`. `Utf8` and `Gbk` write no BOM. The rope is written as-is; do not rewrite mixed newlines.

## Task 7: Find and replace

**Files:**
- Create: `crates/aitext-core/src/find.rs`
- Modify: `crates/aitext-core/src/lib.rs`

**Interfaces:**
- Consumes: `Document`, locked `FindQuery`, `Match`, `Direction`
- Produces:

```rust
impl Document {
    pub fn find(&self, query: &FindQuery, from: Offset, direction: Direction) -> Option<Match>;
    pub fn find_all(&self, query: &FindQuery) -> Vec<Match>;
    pub fn replace_current(&mut self, query: &FindQuery, replacement: &str) -> bool;
    pub fn replace_all(&mut self, query: &FindQuery, replacement: &str) -> usize;
}
```

Rules:

- Empty query matches nothing.
- `match_case == false` compares with Unicode lowercase via `to_lowercase()`. Because lowercase can change width, implement search on a lowered copy **only when the query and haystack lowercasing preserve 1:1 char offsets**. For v1, if any character in the document or query has a lowercase mapping whose `chars().count()` differs from 1, fall back to scanning with a window and comparing lowered strings without assuming equal length. Preferred simple implementation: walk every start offset and compare the next `query.chars().count()` chars after optional lowercasing of both slices.
- Whole word: both sides of the match are at a boundary. A boundary is start/end of document or a transition between `char::is_alphanumeric() || c == '_'` and something else.
- `replace_current` replaces the current selection if that selection equals the current match for `query`; otherwise it finds forward from caret and replaces the first hit.
- `replace_all` is one undo step. Implement it as a single `Edit` covering the whole replacement, not N undo records.

```rust
pub fn take_snapshot(doc: &Document, generation: u64) -> CompletionSnapshot;

pub trait Transport: Send + Sync {
    fn complete(&self, snapshot: CompletionSnapshot, cancel: CancelFlag) -> Result<String, CompletionError>;
}

#[derive(Clone, Debug)]
pub enum CompletionError {
    NotConfigured,
    Timeout,
    AuthFailed,
    Empty,
    RequestFailed(String),
    Cancelled,
}

pub struct CompletionEngine<T: Transport> {
    pub transport: T,
    pub debounce_ms: u64,
    pub configured: bool,
    pub enabled: bool,
}

impl<T: Transport> CompletionEngine<T> {
    pub fn on_change(&mut self, now_ms: u64, snapshot: CompletionSnapshot, selection_empty: bool, composing: bool, readonly: bool, too_large: bool) -> EngineEvent;
    pub fn on_tick(&mut self, now_ms: u64) -> EngineEvent;
    pub fn on_result(&mut self, generation: u64, result: Result<String, CompletionError>) -> EngineEvent;
    pub fn apply_typed_prefix(&mut self, typed: &str) -> Option<GhostSuggestion>;
    pub fn suggestion(&self) -> Option<&GhostSuggestion>;
    pub fn state(&self) -> CompletionState;
    pub fn reject(&mut self);
    pub fn take_accept(&mut self) -> Option<String>;
}

pub enum EngineEvent {
    None,
    StartRequest { snapshot: CompletionSnapshot },
    CancelRequest { generation: u64 },
    StateChanged,
}
```

`take_snapshot`: last 4000 chars before caret, first 500 after caret, `display_name()`, language as a stable lowercase string: `plain markdown json toml rust python c cpp javascript typescript powershell batch ini`.

`shape_suggestion`:

1. Strip a leading markdown fence if the whole reply is wrapped in ```
2. If `raw` starts with `prefix`, strip that prefix
3. Truncate to 120 chars or 4 lines
4. Trim trailing whitespace
5. Empty => `None`

Engine rules:

- The engine owns `generation`. `on_change` increments it, stores the snapshot with the new generation, clears any visible suggestion, and starts the debounce timer.
- The caller does not pass a generation into `on_change`. `take_snapshot(doc, 0)` may still exist for tests, but `on_change` overwrites `snapshot.generation`.
- The shell calls `apply_typed_prefix` when the user inserted text that is a prefix of the current suggestion. If that returns `Some`, do not call `on_change` and do not bump generation.
- Do not request when not configured, disabled, composing, non-empty selection, readonly, too_large, or in backoff.
- After 3 consecutive `on_result` errors other than `Cancelled` and `Empty`, enter backoff until `now_ms + 5000`. `Empty` sets `NoSuggestion` and does not count as a failure.
- Success, `configured` flipping, or `enabled` toggling from false to true clears backoff and failure count.

The engine does not spawn threads. It returns `StartRequest` / `CancelRequest`. The shell owns the worker thread.
