# Aitext v0.2.0

Aitext v0.2.0 hardens inline completion for real editor workflows while keeping the lightweight Windows-native writing surface.

Highlights:

- Real SSE streaming for OpenAI Chat Completions, DeepSeek FIM, Responses, Anthropic, and compatible endpoints.
- Ghost text appears as soon as the first valid stream chunk arrives and updates in place until completion.
- Profile, document, generation, revision, and cancellation guards reject late or cross-document results.
- Tab creation, tab selection, tab switching, file opening, IME preedit, edits, and document clearing invalidate obsolete completion work.
- Bounded prefix and suffix snapshots avoid copying an entire large document for every request.
- Language-aware completion prompts and shaping for code, Markdown, and plain text, including Chinese and mixed-language input.
- Existing suffix echoes are removed before a suggestion reaches the editor, preventing duplicate text after acceptance.
- In-memory completion diagnostics expose request, first-chunk, completion, acceptance, cancellation, and failure metrics without persisting document content or API keys.
- API and model discovery remain separate from document completion and continue to use offline fixture-backed tests.
- Aitext package, executable, configuration namespace, installer, portable archive, and release assets use the Aitext identity and versioned names.

This release is unsigned. Windows SmartScreen may show an unknown-publisher warning before installation. Verify downloaded assets with `SHA256SUMS.txt` when needed.
