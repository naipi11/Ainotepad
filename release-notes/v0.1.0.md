# Ainotepad v0.1.0

## English

First formal Ainotepad release: a lightweight Windows-native text and code editor with inline ghost-text completion at the caret.

Highlights:

- Paper Cut editor shell with White, Black Green, VS Code, macOS Light, Dark, Lamp, High Contrast, and Custom themes.
- English, Simplified Chinese, and Follow Windows interface language modes.
- Provider profiles for DeepSeek, OpenAI, xAI/Grok, Anthropic/Claude, and custom endpoints.
- FIM, Chat Completions, and Responses adapters where supported.
- Green ghost-text preview with Tab acceptance and Esc dismissal.
- Chinese IME caret anchoring, syntax highlighting, tabs, find/replace, undo/redo, and DPAPI-backed API keys.
- Unsigned Windows installer, portable ZIP, and SHA256 checksums.

This release is unsigned. Windows SmartScreen may show an unknown-publisher warning before installation.

## 简体中文

Ainotepad 首个正式版本：一款轻量级 Windows 原生文本/代码编辑器，在光标处提供幽灵字补全。

主要内容：

- Paper Cut 编辑器外壳，支持白色、黑绿、VS Code、macOS 浅色、暗黑、纸灯、高对比度和自定义主题。
- English、简体中文、跟随 Windows 三种界面语言。
- 支持 DeepSeek、OpenAI、xAI/Grok、Anthropic/Claude 和自定义端点配置。
- 在对应服务商上支持 FIM、Chat Completions、Responses 适配器。
- 绿色幽灵字预览，Tab 接受，Esc 关闭。
- 中文输入法光标定位、语法高亮、多标签、查找替换、撤销重做和 DPAPI API Key 存储。
- 提供未签名 Windows 安装包、便携版 ZIP 和 SHA256 校验文件。

本版本未进行代码签名。Windows SmartScreen 可能在安装前显示“未知发布者”提示。
